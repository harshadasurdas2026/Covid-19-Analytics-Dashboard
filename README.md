# 🌍 COVID-19 Analytics Dashboard (Power BI)

A comprehensive and interactive *COVID-19 Analytics Dashboard* built using *Microsoft Power BI*. This project visualizes global and country-level pandemic data, tracking key metrics including total cases, deaths, recoveries, vaccination progress, and recovery rates over time.

---

## 📊 Dashboard Preview

### Page 1: Overview & Key Metrics
* *KPI Cards:* Highlights Total Cases (32M), Total Deaths (643K), Total Recovered (28M), Active Cases (3M), and Recovery Rate (88.72%).
* *Visualizations:*
  * *Global Map & Regional Breakdown:* Geographic distribution of cases across continents (North America, Europe, Africa, South America, Asia, etc.).
  * *Vaccinated by Country:* Trend and comparison charts tracking vaccination progress across major nations (USA, Brazil, India, UK, France, Germany, Japan).
  * *Recovery Rate by Country:* Bar charts comparing recovery efficiencies.
  * *Total Cases by Month:* Monthly progression and wave analysis from January to June.

### Page 2: Detailed Tabular Data & Time-Series
* A structured tabular view detailing daily metrics:
  * *Date* (e.g., January 2021 records)
  * *Total Cases*
  * *Active Cases*
  * *Total Death*
  * *Total Recovered*
  * *Sum of Vaccinated*
* Includes cumulative totals at the bottom for quick data auditing and summary analysis.

---

## 🛠️ Key Features & Insights
* *Real-Time KPI Tracking:* Instant visibility into critical health indicators.
* *Geospatial & Trend Analysis:* Interactive maps and line charts showing regional impact and vaccination drives.
* *Granular Data Exploration:* Multi-page layout allowing high-level overview (Page 1) as well as granular row-level data inspection (Page 2).

---

## 🚀 Built With
* *Tool:* Microsoft Power BI
* *Data Fields:* Date, Total Cases, Active Cases, Total Deaths, Total Recovered, Vaccinated.

---

## ⚙️ How to Use / View Locally
1. Download the .pbix file from this repository.
2. Open it using *Microsoft Power BI Desktop*.
3. Explore the interactive filters, drill-throughs, and page navigations.
